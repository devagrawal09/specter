03 · Repairs completed

What the six-round process improved.

The branch includes six earlier repair commits plus the round-6 repair set. Together they close the original defects and all fourteen issues reported by round 5.

Original

Five reported protocol defects closed

  • Go Reaction passes no longer silently skip queued commit ranges.
  • Telemetry retries keep an immutable request-ID-to-batch identity, preventing acknowledgements from discarding changed observations.
  • Duplicate Command executions return stable Reaction tickets in TypeScript and Go.
  • Public Query and subscription errors are sanitized instead of exposing arbitrary runtime messages.
  • Go subscription errors terminate the SSE stream.
Rounds 1–2

Lifecycle, idempotency, and transport semantics hardened

  • Command completion, retry identity, cancellation, terminal messages, and ticket behavior gained regression coverage.
  • Structured error mapping and internal-error redaction were aligned across server and client paths.
  • CI build ordering and protocol package consumption were corrected.
  • Event ordering, causal metadata, acknowledgement accounting, and HTTP/SSE edge cases were tightened.
Round 3

Collector concurrency and recovery made durable

  • Collector request reservations and deduplication were made safe under concurrent ingestion.
  • Producer lifecycle, collector outage, retry, restart, and rotation scenarios received focused tests.
  • Protocol lifecycle edges and non-recursive collector behavior were reinforced.
Round 4

Schema fidelity, recovery, and parsing gaps closed

  • Go now rejects null or mistyped known optionals, unsafe integers, invalid causal arrays, and malformed Event references.
  • Go SSE parsing supports multiline data, comments, optional spacing, EOF blocks, and exact JSON media types.
  • TypeScript subscription setup failures are correlated and sanitized; content types and acknowledgements are validated more strictly.
  • Normative schemas now model full Event references and standardized observation fields, validated with Ajv 2020 fixtures.
  • Collector startup reconciles interrupted reservations against durable events across rotated segments.
  • Rotation size accounts for SQLite database, WAL, and rollback-journal bytes.
Round 5

Fourteen additional gaps identified

The review found scheduler panic, SSE delivery, deduplication lifetime, sequence-zero visibility, refresh ordering, schema validation, stream parsing, trace scaling, and queue-bound defects. Those findings became the round-6 repair scope.

Round 6

All round-5 findings repaired; final review stopped the cycle

  • Go Reaction panics now fail tickets without stranding the scheduler or shutdown; subscription refreshes use generations and fresh causal operations.
  • Go SSE delivery preserves the newest value before terminal frames and enforces sequence and event-name rules; request and response field validation is stricter.
  • TypeScript SSE framing now survives CR, LF, CRLF, UTF-8, and arbitrary chunk boundaries; observation acknowledgements require exact accounting.
  • Collector reservations are not reclaimed while live, sequence zero is visible, traces use adjacency traversal, and total retained telemetry respects the configured bound.
  • Focused regressions increased protocol coverage to 45 tests and observability coverage to 35 tests.

The independent review then confirmed nine remaining findings, all closed by the final repair pass below.

04 · Final resolutions

Nine findings, nine tested repairs.

The last two P1 and seven P2 issues are now fixed at their protocol boundaries, with regression tests preserving each corrected behavior.

Fixed · Ack integrity

Telemetry acknowledgements use an immutable snapshot

The TypeScript client deep-clones submitted observations before sending and validates the response against that exact snapshot.

packages/protocol/src/http-client.ts
Fixed · Duplicate persistence

Durable commits retain and reconcile their reservation

A post-commit control-index failure preserves ownership. A retry reconciles the targeted abandoned reservation against durable segments before deduplicating it.

packages/observability/src/cli.ts
Fixed · SSE conformance

TypeScript enforces event names and strict sequence order

SSE frames preserve event: metadata, require it to match the message kind, and reject duplicate, decreasing, or stale sequences.

packages/protocol/src/http-client.ts
Fixed · Lifecycle completeness

Go panic recovery emits terminal failure observations

Reaction handler and Slice apply panics become structured infrastructure failures paired with reaction.run.failed or slice.catch-up.failed.

runtimes/go/specter/runtime.go
Fixed · Stream parsing

Go accepts CR, LF, and CRLF SSE delimiters

A protocol-specific scanner split function handles all standard SSE line endings, including a carriage return split across input chunks.

runtimes/go/protocol/client.go
Fixed · Ack schema

Go rejects null rejected-observation IDs

When present, rejectedObservationIds must decode from a JSON array before acknowledgement accounting proceeds.

runtimes/go/protocol/client.go
Fixed · Normative alignment

Capability names are unique everywhere

The behavior specification, JSON Schema, TypeScript validator, and Go implementation now agree that every capability array contains unique names.

runtimes/go/protocol/types.go · protocol/schemas/messages.schema.json
Fixed · Error classification

Go requires a JSON object before envelope validation

A null or other non-object root now returns the shared invalid-message error, while malformed JSON remains classified separately.

runtimes/go/protocol/server.go
Fixed · Storage bound

Producer retries and dedup retention share a finite horizon

TypeScript and Go producers share the collector's 48-hour default, report expired unacknowledged batches as dropped, and never retry after accepted identities may be pruned.
