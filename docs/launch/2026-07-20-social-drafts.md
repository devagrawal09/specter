## LinkedIn

I’m opening Specter for public preview. It’s a TypeScript framework built around
executable Slice specifications: each feature keeps its behavior contract,
implementation, and exact scenarios close together. That gives coding agents a
smaller, explicit boundary to work inside—and gives the application a way to
check that the result still conforms.

The preview also includes an ordered Event Log, private replayable Slice State,
typed command/query/subscription envelopes, and project-owned transports. The
capabilities reinforce each other: agents get inspectable context, scenarios
make the intended behavior executable, and durable events preserve what the
application accepted.

Give it to your agent: https://devagrawal09.github.io/specter/

This preview tracks the main branch. npm 0.3.0 is not published yet.
